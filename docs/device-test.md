# 真机验证清单

目标是回答两个问题：

1. iOS 的 Wi-Fi 代理填 `127.0.0.1:8888`，系统是否真的把流量送进 App；
2. B 站 App 是否走系统代理。

## 步骤

1. **装 App**：Xcode 选自己的 Team + 唯一 Bundle ID，连 iPhone Run；首次运行后到
   设置 → 通用 → VPN 与设备管理 里信任开发者。
2. **开代理**：打开 App，开关应为「代理运行中」。若提示端口被占用，先关掉占用 8888
   的 App。
3. **装证书**：点「安装根证书」→ Safari 提示下载描述文件 → 允许 → 设置 →
   已下载描述文件 → 安装。然后 设置 → 通用 → 关于本机 → 证书信任设置，把
   `BiliScope Root CA` 的完全信任打开。
4. **回 App 看状态**：应显示绿点「根证书已信任」。点「运行自检」，应在一两秒内出现
   `✅ 通过：…（206，… 字节）`。

   > 装完描述文件**不等于**已信任。iOS 还要在 设置 → 通用 → 关于本机（页面最底部）
   > → 证书信任设置 里，把 `BiliScope Root CA` 的开关打开。英文界面是
   > Settings → General → About → Certificate Trust Settings。
5. **改代理**：先确认 App 已经启动并停在界面上，再去改代理，否则手机会断网
   （设置 → 无线局域网 → 当前网络 ⓘ → 配置代理 → 手动）：
   服务器 `127.0.0.1`，端口 `8888`，**认证保持关闭**（本代理不支持用户名密码，
   开了认证会直接连不上），存储。
6. **播 B 站**：打开 B 站 App，随便点开一个视频，播 10–20 秒。
7. **回 App**：看「B 站连接 / 加速」计数和日志，点日志右上角分享，发我。

## 装完打不开？

**「Developer App Certificate is not trusted」**：这是**签名证书**没被信任，和根证书是两回事。

设置 → 通用 → VPN 与设备管理 → 开发者 App → 点你的 Apple ID → 信任。英文界面是
Settings → General → VPN & Device Management → Developer App → 你的邮箱 → Trust。

免费账号签名 7 天过期，到期后重新 Run 一次，必要时再信任一次。

## 四步诊断怎么读

App 里的「运行诊断」会依次做五件事：

1. 连本机代理端口 `127.0.0.1:8888`（回环，不需要外网权限）；
2. 发一个 CONNECT，看代理是否应答 200；
3. 经代理访问视频 CDN 根路径（返回 403 是正常的，说明 TLS 和网络都通）；
4. **绕开系统代理**，用裸 TLS 直连视频 CDN（`NWConnection`，不受 Wi-Fi 代理影响）；
5. 直连 `1.1.1.1:443`，确认这个 App 本身有没有外网。

| 现象 | 结论 |
| --- | --- |
| ⑤ 失败 | App 本身没网：检查 设置 → 哔哩加速 → 无线数据 是否被关，或当前网络是否正常 |
| ⑤ 正常、④ 失败 | 网络能出去，但到 B 站 CDN 不通（DNS 污染、运营商拦截、或该 CDN 在你这里不可达） |
| ④ 正常、③ 失败 | 代理自身的问题，日志里找 `probe fail … 8000ms` |
| ③④⑤ 都失败但 Safari 能上网 | 多半是这个 App 的蜂窝数据权限被关了 |

## 结果怎么读

| 现象 | 含义 | 下一步 |
| --- | --- | --- |
| 自检失败，提示「根证书还没被系统信任」 | 证书没装或没开完全信任 | 重做第 3 步 |
| 自检一直「检测中…」 | 代理端口不通 | 确认开关打开；换 8888 以外的端口重试 |
| 改了 Wi-Fi 代理后 B 站直接没网 | iOS 不接受 `127.0.0.1` 作为代理 | 回 App 把监听地址切到「Wi-Fi 地址」，代理改填手机自己的 IP |
| B 站能播，但「B 站连接」一直是 0 | **B 站 App 没走系统代理** | 走局域网退路（README「Mac 常开 + 局域网代理」） |
| 有 `tunnel api.bilibili.com`，没有 `accelerated` | 走了代理，但视频不在 B 站自有 CDN（可能被分到 Akamai） | 正常现象，这类视频不受加速影响 |
| 出现 `accelerated … via upos-…ov` | 接管且镜像竞速生效 | 成功 |
| 出现 `accelerated` 但播放仍卡 | 加速生效，瓶颈在本地带宽或 CDN | 调大并发或换 CDN 模式 |

## 收尾

不用时：设置 → 无线局域网 → 配置代理 → 关闭；需要彻底移除时，设置 → 通用 →
VPN 与设备管理 删除描述文件，并在证书信任设置里关掉。

## 已知限制

- 只有 Wi-Fi 生效，蜂窝网络下系统代理不生效；
- 免费账号签名 7 天过期，过期后重新 Run；
- App 被杀掉后代理停止，B 站会报网络错误，重新打开 App 即可；
- 只接管 B 站域名，其他 App 的流量只是字节转发，日志里不会出现它们的域名。
